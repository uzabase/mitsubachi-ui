# mitsubachi-ui

## インストール

```bash
npm install @uzabase/mitsubachi-ui@<version>
```

## 使い方

コンポーネントは Web Components として利用できます。ライブラリの読み込み方法は利用環境に合わせて選択してください。以下は TypeScript から読み込む例です。

```ts
import "@uzabase/mitsubachi-ui";
```

```html
<mi-neutral-button>送信</mi-neutral-button>
```
